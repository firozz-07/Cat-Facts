# 🐱 Cat Fact Website

A simple website that displays random cat facts using **JavaScript and a REST API**.

## ✨ Features

* Fetch random cat facts
* Get a new fact with one click
* Dynamic content updates
* Responsive design

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript
* REST API


## 🧠 Concepts Used

* Fetch API
* Promises & async operations
* JSON
* DOM manipulation
* Event handling

## 🚀 Run Locally

Clone the repository and open `index.html` in your browser or use **VS Code Live Server**.
